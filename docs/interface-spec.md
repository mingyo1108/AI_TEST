# 외부 연동 규격 — 제휴몰 재고 연동 (v1.2)

이 시스템은 송신 I/F 테이블 `partner_stock_if`에 재고를 쓰고, 연동 서버가 이를 읽어 제휴몰(오늘장터 PTA, 싱싱마켓 PTB)로 보낸다.

30분마다 재고가 남은 로트(판매 가능·판매 보류)를 로트 단위로 보낸다. 소진 로트는 보내지 않는다.

## 1. 항목

| 항목 | 컬럼 | 형식 | 필수 | 설명 |
|---|---|---|---|---|
| 상품 코드 | product_code | 문자 20 | 필수 | |
| 로트 번호 | lot_no | 문자 20 | 필수 | |
| 수량 | qty | 숫자 | 필수 | |
| 재고 상태 | stock_status | 문자 3 | 필수 | 2장 상태 코드 |

## 2. 재고 상태 코드

| 코드 | 이름 | 제휴몰에서의 처리 |
|---|---|---|
| AVL | 판매가능 | 판매 가능 재고에 더한다 |
| HLD | 일시 판매중지 | 판매 가능 재고에서 뺀다. 상품 페이지에 "일시품절"로 보인다 (검사 등으로 잠시 막은 재고) |
| STP | 판매불가 | 판매 가능 재고에서 뺀다. 상품 페이지에 "판매종료"로 보인다 (다시 팔 수 없는 재고) |

- 같은 로트가 다시 AVL로 오면 제휴몰은 판매를 재개한다.
- 위 표에 없는 코드가 오면 제휴몰은 연동 묶음 전체를 거부한다.

## 3. 송신 테이블 운용

- 이 시스템은 회차마다 그 시각의 재고를 `partner_stock_if`에 INSERT만 한다. 한 회차의 행은 같은 `sent_at`을 갖는다 (`if_id`는 순번).
- 연동 서버는 `sent_at`이 가장 늦은 회차를 읽어 제휴몰로 보내고, 보낸 회차는 연동 서버가 보관 기간(7일)이 지나면 지운다.
- 배치는 배치 서버 한 대에서만 돈다 (`shop.scheduling.enabled`). 회차가 겹쳐 쓰이지 않는다.
